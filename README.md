# مولّد تصاريح النقل السياحي — Tasare7

تطبيق Flask عربي RTL لإنشاء تصريح نقل سياحي مصري من استمارات الشركة الأصلية، مع 3 نسخ إخطار، صورة إدارة البرامج اختيارياً، و3 نسخ نيم ليست.

## الشركات

- ميمورى تريب تورز — ترخيص 1586

## التشغيل محلياً

1. ثبّت Python 3.11+ وLibreOffice.
2. أنشئ بيئة افتراضية وثبّت الحزم:

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

3. شغّل التطبيق:

```bash
flask --app api.index run --host 0.0.0.0 --port 8080
```

ثم افتح `http://localhost:8080`.

## مهم — الاستمارات الأصلية

مجلد `stamps/` يحتوي ملفات Word الأصلية المتاحة مباشرة، ومجلد `assets/legacy_templates/` يحتوي نسخ PDF المرجعية للاستمارات القديمة التي كانت محفوظة بصيغة `.doc` ولا يمكن للخادم الحالي استيراد بايتاتها من مكتبة ChatGPT.

التطبيق لا يعيد رسم نموذج رقم (6) من الصفر: عند توفر DOCX الأصلي يستخدمه، يملأ الخانات المعروفة ثم يحوّله عبر LibreOffice إلى PDF ويحافظ على الصفحات الثلاث الأولى فقط. أما القوالب القديمة المحفوظة بصيغة PDF فتستخدم كخلفية مرجعية حتى يتم استبدالها بملفات DOC/DOCX الأصلية.

- لا يتم اختراع أسماء أو أرقام جوازات إذا كان العدد لا يطابق النيم ليست؛ يرفض التطبيق الطلب.

## النيم ليست

يدعم التطبيق عناوين Excel الشائعة بالعربية والإنجليزية والصينية، ويكتشف صف العناوين تلقائياً ضمن أول 30 صفاً.

## الإنتاج

يجب تشغيل التطبيق على VM أو Render/Railway/Docker host يدعم LibreOffice. لا تعتمد على Vercel Serverless لتشغيل مولد Word/PDF هذا.

## نشر على Render

المشروع يحتوي `Dockerfile` يثبت LibreOffice داخل الحاوية. أنشئ Web Service من مستودع GitHub واختر Docker، ثم استخدم `render.yaml` أو الإعدادات الافتراضية. المنفذ المستخدم داخل الحاوية هو `8080`.
